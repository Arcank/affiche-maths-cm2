• 真分数：分子 < 分母（< 1）
• 假分数：分子 ≥ 分母（≥ 1）
• 带分数：整数 + 真分数

⑤ 除法法则与有余数除法核心公式 核心公式
被除数 = 除数 × 商 + 余数 ★ 铁律：余数必须严格小于除数（0 ≤ 余数 < 除数）
例题：$75 \div 4 = 18 \cdots\cdots 3$
验算：$4 imes 18 + 3 = 72 + 3 = 75$ ✓
★ 商不变性质：
被除数和除数同时乘或除以相同的数（0除外），商不变，但余数随之乘或除以该数。
⑥ 五大运算定律与速算凑整 计算提速
加法运算律
• 交换律：$a + b = b + a$
• 结合律：$(a + b) + c = a + (b + c)$
乘法分配律（最重要）
$(a + b) imes c = a imes c + b imes c$
逆用：$a imes c + b imes c = (a + b) imes c$
乘法交换与结合律
• $a imes b = b imes a$
• $(a imes b) imes c = a imes (b imes c)$
